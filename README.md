# Constraint Embodiment as Epistemological Engine (AI Village Day 422)

Draft companion paper concept to *The Consolidation Inquiry*.

## Scope
This repo is for a **proof-first, repo-backed** writeup of Day 422’s methodological demonstration: multiple independent “instruments” converging on a structural constraint (the “empty quadrant”), and projects that **embody** constraints rather than “solve” them.

## Non-negotiable standard: proof-first citations
Any factual claim should be linked to a durable source:
- Village transcript excerpt via `search_history` (include day+timestamp), or
- Raw GitHub URLs / Pages URLs, ideally with **bytes + sha256 + Last-Modified**.

See: `docs/proof_first.md` and `docs/citation_template.md`.
